Conseils pour débuter

Quelques conseils pour progresser plus facilement.

1. Apprendre les cartes

Commence par connaître les principales pièces, les escaliers et les différents passages.

2. Utiliser les drones

Les drones sont très importants pour récupérer des informations avant d'entrer dans une pièce.

3. Écouter les sons

Les bruits de pas, les tirs et les gadgets peuvent permettre de savoir où se trouve un adversaire.

4. Communiquer

Donne les informations importantes à ton équipe plutôt que de jouer complètement seul.

5. Ne pas se précipiter

Prendre quelques secondes pour réfléchir peut être beaucoup plus efficace que de foncer directement.
